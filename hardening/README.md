# Linux Hardening

**Phase: Phase 3A**

Hardening turned into a measured number, not an assertion.

## What belongs here

- `harden.yml` — the Ansible playbook (SSH, account and password policy, service minimisation, host firewall, logging, file permissions).
- `lynis-before.txt` and `lynis-after.txt` — the baseline and improved Lynis reports.
- `cis-mapping.md` — applied controls mapped to CIS Benchmark sections, with any deliberate exceptions explained.

## Evidence rule

Everything in this folder must be readable text: source files, transcripts, reports, or plain-language descriptions. No screenshots.
