# AI Feature

**Phase: Phase 4**

A small, local, zero-cost AI feature appropriate to your persona, plus an honest risk assessment.

## What belongs here

- the feature source (for example `fraud_model.py`) — runs locally, no API key, text output.
- `ai-risk-assessment.md` — mapped to a recognised framework: data provenance, model behaviour, misuse, bias in the South African context, human oversight.
- `ai-governance.md` — what is logged, what a human must approve, how it is monitored, and when it is switched off.

## Evidence rule

Everything in this folder must be readable text: source files, transcripts, reports, or plain-language descriptions. No screenshots.
