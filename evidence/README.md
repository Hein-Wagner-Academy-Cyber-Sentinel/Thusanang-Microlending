# Evidence

**Phase: All year**

The text-native proof behind every claim in your portfolio. If you assert something, the proof lives here.

## What belongs here

- `*.cast` — asciinema recordings of terminal sessions.
- scanner reports, log extracts, and pipeline run records, each named clearly by phase and date.
- Nothing here is a screenshot. If you are tempted to screenshot, capture the terminal output or the file instead.

## Evidence rule

Everything in this folder must be readable text: source files, transcripts, reports, or plain-language descriptions. No screenshots.
